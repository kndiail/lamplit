# 提灯者 · LAMPLIT

> v4.3「节拍与石柱」——第三层音游层主、下落/魔法新怪、房间掩体与更干净的主菜单。

> 一款纯手写像素风的「类幸存者」动作游戏。灯是唯一的武器，也是唯一的视野。
> 没有美术素材、没有音频素材、没有构建步骤 —— 所有像素、光、音乐都在运行时由代码生成。
>
> **v3.0「五层地牢」**：从无尽生存改成地牢探险 —— 5 层，每层 10 关，房间随机生成，
> 清场后走进传送门前进；每层第 10 关是层主，击败后选择「灯火祝福」再下一层。
> 保留并整合了 v2 的剧情、圣物、进化、技能与无尽深潜。

## 双击开玩（Windows）

`dist/提灯者.exe` 是打包好的单文件版本（约 1.2 MB，无需安装）：

- 双击后在 `127.0.0.1` 上启动内置服务，自动用默认浏览器打开游戏
- **首次启动会自动清空一次存档**（`?reset=1`），之后正常保存
- 关闭浏览器不会退出程序：在任务栏托盘图标右键 → 退出；托盘里也有「重置存档并重开」
- 重新打包：`python tools/build_exe.py`（用系统自带 csc.exe，无需联网）

## 手机 / Android

- **PWA（最快）**：用 Chrome 打开游戏地址 → 菜单「添加到主屏幕」，即可以全屏横屏、离线运行
- **APK**：先 `python tools/sync_android.py` 同步网页资源，再用 Android Studio 打开 `android/` 构建
  （本机已有 Android SDK；需安装 JDK 17）
- 触屏操作：左半屏虚拟摇杆、右下「冲 / 灯」按钮、左上暂停；音游四轨可直接点击轨道击打
- PWA 入口：`manifest.webmanifest`、`sw.js`（离线缓存）

## 立刻开玩

```bash
# 随便一个静态服务器即可（不需要构建、不需要依赖）
python -m http.server 8080
# 然后打开 http://127.0.0.1:8080/index.html
# 想清空浏览器里的存档：打开 http://127.0.0.1:8080/index.html?reset=1 一次即可
```

也可以直接双击 `index.html`（file:// 同样可运行）。
推荐 1080p 及以上分辨率：画布固定 384×216，浏览器会做整数倍放大，保持像素锐利。

## 玩法

你是长夜里唯一的提灯者。灯光半径就是你的视野与安全区，圈外的东西会悄悄靠近。

**地牢结构：4 层 × 6 关，每两关一位层主（共 12 位，招式与美术全部不重样）**

| 层 | 主题池（每层随机抽一个） | 层主 |
| --- | --- | --- |
| 1 | 森林 / 冰原 / 沙漠遗迹 | 灯笼吞噬者 · 灰烬守夜人 · 钟楼执事 |
| 2 | 骷髅墓穴 / 骑士城堡 / 万圣夜 | 深黯之母 · 沼泽主教 · 沉钟行者 |
| 3 | 外星基地 / 火山 / 泥油海岛 | 节拍收藏家 · 风蚀巨像 · 断桥织网者 |
| 4 | 巨石山脉 / 深黯长夜 | 长夜之核 · 镜之守夜人 · 提灯者的倒影 |

**每关是一张房间图，不是一间房**

- **主干 + 支线**：从初始房随机游走 3~5 间小怪房，终点是传送门房；
  支线挂在主干旁边（宝箱房、特殊房、精英房、牢笼房），首领关是 3 间基础房围住首领房
- **走廊连接**：相邻房间在四边中点开门，用走廊连起来；门洞、墙体、刷怪点、陷阱全部由种子决定，
  同一天（每日挑战）所有人拿到同一张地图
- **锁门分波**：踏进战斗房，门闸落下，怪分 1~2 波刷出；清完才开门，还掉一颗心和魂火
- **传送门在终点房**：房间清空后中央亮起传送门，走进去前往下一关；每层第 10 关是首领房
- **小地图**：进关即公开房间类型与连接关系，未探索更暗、当前房间高亮——规划路线用，不做战争迷雾
- **房间类型**：初始房 / 小怪房 / 精英房（深红门、全精英）/ 牢笼房 / 宝箱房（圣物三选一）/
  特殊房（祭坛祝福）/ 传送门房 / 首领房 / 隐藏房（小地图上不显示，进去才知道）
- **新怪**：重砸者（预警圈 → 砸落，圈内重伤）/ 咒术师（读条后在脚下留下持续伤害与减速的魔法场）
- **层主房**：进门回 30% 血，层主半血进入二阶段；击败后传送门亮起，出门选一次灯火祝福
- **灯火祝福**：层间三选一（暖火 / 圣物 / 伤害 / 灯光 / 移速 / 技能冷却 / 护甲）
- **自动攻击**：武器自动索敌，你专心走位与冲刺；**房间里没有敌人时不会空放**
- **清场吸附**：一层小关清空后，本关所有魂火/心自动飞向玩家
- **房间掩体**：石柱、断墙、环阵等四类布局，参与碰撞与子弹阻挡，不再是光秃秃的空地
- **祭坛**：踩上去三选一祝福，不消耗任何东西
- **宝箱**：宝箱房里有圣物三选一（降频后约每 7 关才遇到一间宝箱房，特殊祭坛房约每 10 关一间）
- **进化**：武器满级 + 指定被动 3 级 → 升级卡里出现进化形态
- **神器单槽**：同时只装配一件神器（最高 Lv.3）。升级卡/宝箱里选到另一件会直接换装，
  旧神器进收藏栏、**不再提供任何加成**；选到已装配的那件则升级
- **主动技能**：`E` 释放灯爆，炸开近身敌人并击退，冷却 13 秒
- **无尽深潜**：通关 5 层后可在结算界面按 `E`，继续第 6 层、第 7 层……敌人与层主持续变强

### 角色

| 角色 | 特点 | 解锁 |
| --- | --- | --- |
| 提灯者 | 灯光更亮、拾取更远，星火弩起手 | 初始 |
| 守墓人 | 生命 40，镰影近战起手 | 击败第一位层主 |
| 游侠 | 移速 +15%，萤火起手 | 通关一次 |

进度（最长生存 / 最高击杀 / 通关次数 / 解锁角色）保存在 `localStorage`。

**中途存档**：每关开始自动存一份进度（层 / 关 / 角色 / 武器 / 被动 / 圣物 / 血量）。
暂停界面选「保存并返回主菜单」后，标题界面会出现「继续旅程 · 第X层 Y/10」，
按空格或点它即可从当前层继续；按 `N` 放弃进度重开。

**难度成长**：敌人血量 / 伤害 / 速度按「层 + 关」双轴提升（第 5 层比第 1 层强约 4 倍），
精英率与高阶怪种随关数解锁。层主二阶段提前到 62% 血，弹幕更多、冲锋更快。

**入场演出**：每一关开局有一道落下光柱与尘土环；层主房会拉黑边遮幅、层主从上方砸落并震屏，
名片滑入（空格可跳过）。战斗房落闸有门轴扬尘与微震，清场有金色冲击环，开箱有光柱粒子。

**状态效果**：圣钟与霜华会减速甚至定身，灯油让攻击附加燃烧（持续伤害），
血月环会造成流血，噬光蛭会临时夺走你的一部分灯光——光圈缩小，视野变窄。

**精英怪**：头顶戴王冠，血量 ×4.2、伤害 ×1.4、掉落 4 倍魂火，55% 概率掉心。

### 剧情

- **序章**：首次进入游戏自动播放五页（可跳过），之后可在「故事」页重看
- **记忆碎片**：8 片，靠实战达成条件解锁（活过 60 秒、击杀数、击杀看守者、收齐武器……），
  集齐后再通关会进入**真结局**
- **看守者台词**：两位 BOSS 出场与半血时会有对话框，死亡时有一句遗言
- **结局**：普通通关 / 真结局 / 死亡，三种文本，结算界面按 `F` 可阅读全文

### 元系统

**图鉴**（标题界面 `C`）—— 敌人 8 种、武器 6 种、被动 10 种，共 24 条。
每一项都要在实战中「遇见」才会解锁：敌人需要被刷出来，武器/被动需要真正拿到过。
未解锁的条目显示为剪影与 `？？？`，解锁后可以读到数值、传说与用法提示。
四个页签（敌人 / 武器 / 被动 / 成就）都可以用方向键浏览，鼠标悬停也能选中。

**成就** 13 个，覆盖不同玩法风格：点亮第一盏灯、百人斩、五百人斩、长夜已明（通关）、
第一夜（击败第一位层主）、全副武装（6 件武器满级）、三生万物（10 种被动各至少 1 级）、
不动如山（60 秒不受伤）、拾光者（单局 300 魂火）、千魂（累计 1000 击杀）、
今日之星（完成一次每日挑战）、抢在黎明之前（03:30 前击杀第一位看守者）。

达成时右上角滑入提示，结算界面还会再列一遍；所有条目都能在「成就」页签查看条件。

**每日挑战**（标题界面 `T`）—— 日期（本地时区 `YYYY-MM-DD`）经 FNV-1a 哈希后
决定当天的角色、起手武器、世界种子与 2 个修正（脆纸灯笼 / 微弱灯火 / 人潮 / 疾行 /
丰饶 / 精英横生 / 铁骨 / 利爪）。所有人同一天遇到的都是同一局，分数按
击杀 × 等级 × 时间 × 伤害综合计算，每日最高分保留最近 14 天。

三个系统共用 `js/meta.js`，存档结构由 `META.ensure()` 自动补全，
老存档升级不会丢进度。

### 一些值得说的细节

**像素精灵全部手写。** 角色/敌人用字符网格描述（`'...o11222211o...'`）再映射到调色板，
包括四方向走路帧、蝙蝠振翅双帧、蠕行者蠕动、幽魂漂浮。BOSS 则是程序化生成的：
噪波轮廓 + 定向光照分色 + 狭长凶眼 + 獠牙巨口 + 利爪，用同一套代码生成两种形态。

**光照是玩法的一部分。** 遮罩在半分辨率画布上先铺满夜色，再用缓存的径向镂空精灵
以 `destination-out` 挖洞，最后整张放大贴回 —— 比每帧创建径向渐变快约 3 倍。
灯笼本身有火苗抖动、随步伐摆动，还会照亮周围的魂火与弹幕。

**音频没有素材文件。** 所有音效都是 `OscillatorNode` + 噪声缓冲的实时合成：
方波射击、带通噪声命中、三角波击杀、噪声扫频冲刺。BGM 是 16 分音符调度器驱动的
芯片音乐（低音、和声垫、脉冲主旋律、琶音、打击），并且会随着战斗强度自动加花，
BOSS 战切换和声与音色。

**确定性世界生成。** 区块按坐标 hash 生成（16px 瓦片 → 256px 区块缓存），
生物群系用低频值噪声（灰烬平原 / 苔沼 / 碎石地 / 枯土）自然过渡；
装饰物（枯树、墓碑、蕨类、蘑菇、骨堆）按权重散布并做 y 排序，雾层是无缝平铺的低分辨率贴图。

**性能。** 常用绘制路径做了缓存：

- 文字：按「内容+颜色+倍率」缓存的 canvas，避免每帧 `fillText`
- 光晕：按颜色缓存的 64×64 径向精灵
- 变色：受击白闪 / 精英染色 用 `source-atop` 染色缓存
- 亮度遮罩：半分辨率 + 镂空精灵
- 屏幕峰值约 60 个敌人 + 弹幕时，单帧渲染中位数从 18.1ms 优化到 5.5ms（无 GPU 加速的无头 Chrome 实测）

## 自动化验证

`tools/shot.js` 是一个零依赖的 Chrome DevTools Protocol 驱动（自建 WebSocket 客户端），
配合 `tools/scenarios/*.js` 场景脚本可以完成：截图、局部放大、模拟键鼠/触摸、
快进模拟、失败即报错。

```bash
# 需要先启动本地静态服务器
python -m http.server 8099

node tools/shot.js tools/scenarios/title.js    # 标题界面
node tools/shot.js tools/scenarios/look.js     # 对局画面（含放大）
node tools/shot.js tools/scenarios/boss.js     # BOSS 战 / 胜利结算
node tools/shot.js tools/scenarios/ui.js       # 各界面布局 + 帧率
node tools/shot.js tools/scenarios/profile.js  # 渲染分段耗时剖析
node tools/shot.js tools/scenarios/touch.js    # 触摸摇杆
node tools/shot.js tools/scenarios/meta.js     # 图鉴 / 成就 / 每日挑战 / 精英王冠
node tools/shot.js tools/scenarios/v2.js       # 新敌人 / 新武器 / 宝箱圣物 / 技能 / 进化 / 二阶段 / 剧情 / 无尽
node tools/shot.js tools/scenarios/v41.js      # 奖励关降频 / 层主入场演出 / 暂停存档与继续 / 跨房间锁定修复
node tools/shot.js tools/scenarios/dungeon.js  # 地牢：房间生成 / 清场 / 传送门 / 层主 / 祝福 / 通关
node tools/shot.js tools/scenarios/dailytest.js # 每日挑战结算与存档回归
node tools/shot.js tools/scenarios/bot.js      # 机器人全流程试玩
```

`bot.js` 会用一个「垂直风筝走位 + 捡魂火 + 贪心选卡」的机器人把整局跑完，
用来验证难度曲线：它通常能打到 2:30~5:30 之间，偶尔通关 —— 人类玩家应更从容。

脚本运行结束后会汇总页面异常与控制台错误，退出码非 0 表示存在问题。

## 设计取舍

- **不做像素缩放滤镜**：整数倍放大 + `image-rendering: pixelated`，像素永远清晰
- **不做 480×270**：最终选 384×216，1080p 下正好 5 倍，角色在屏幕上足够大
- **不做数值膨胀**：满级武器也只有 5 级，靠组合（月轮贴身 + 涟漪清场 + 电弧连锁）取胜
- **不做长对话**：叙事交给一个字幕横幅、一个灯笼、和两位看守者的眼睛
- **图鉴靠「遇见」解锁而不是花钱买**：鼓励换角色、换构筑、多打几局
- **每日挑战只加难度修正，不加新内容**：同一天同一套规则，比的是构筑与走位
- **成就全部可在单局内完成**（除累计类）：不逼玩家刷时长
- **圣物只加「玩法钩子」不加数值**：落雷、冲刺留火、受伤冲击波……每一件都能改变走位方式
- **进化是「构筑目标」**：满级武器 + 3 级被动，给了刷卡的第二个理由，而不是无限堆数值
